# 錦 KIN

一方水、一池錦鯉。可觸摸、投餵與探索的即時 WebGL 日式池塘。

> 讓心，慢下來。 · A moment of stillness.

## 功能

- 即時水面與漣漪模擬
- 錦鯉群游、互動與投餵
- 魚種圖鑑與個人化設定（數量、水波、速度、畫質、音效）
- 全螢幕欣賞

## 需求

- Node.js 18+
- 支援 WebGL2 的瀏覽器（建議開啟硬體加速）

## 開始使用

```bash
npm install
npm run dev
```

瀏覽器開啟終端顯示的本機網址即可。

```bash
npm run build    # 正式建置
npm run preview  # 預覽建置結果
npm test         # 執行測試
```
